# Workspace Portfolio App

A dark, editorial personal portfolio site for **Billy King**.

## Features

- Sticky glass navigation
- Hero with stats
- Selected work grid (data-driven)
- About + experience card
- Skills chips
- Contact form (client-side demo success state)
- Responsive layout, noise texture, accent lime on charcoal

## Open it

Static site — open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Files

| File | Purpose |
|------|---------|
| `index.html` | Structure |
| `styles.css` | Theme & layout |
| `app.js` | Rendering + form logic (pure, exported for tests) |
| `data.js` | Project / experience / skills content |
| `test/app.test.js` | Unit tests (node:test) |

Created as part of an App Builder workspace connectivity test when local shell/write tools were unavailable — files were written via the GitHub API to `billyx86/workspace-portfolio-app`.
